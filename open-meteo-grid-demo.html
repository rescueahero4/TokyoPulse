Click a cell on the map. You'll see what was requested vs what the API returned — the returned lat/lon is the center of the nearest model grid cell, which is why values look "rounded".

How to read this data

1. One request, many points. Open-Meteo accepts comma-separated lat/lon lists, so a whole lattice comes back as one JSON array — one object per point.

2. Values are cell averages. A returned temperature isn't a thermometer at that coordinate; it's the model's value for the whole cell (~1–11 km depending on model).

3. Render as a surface. Because the data tiles space completely, color grading (a raster) is the honest visualization. Dots are for real station measurements.

4. Mind the units. Always read current_units / hourly_units from the response instead of assuming °C or mm.
